🎂 Premium Interactive Birthday Website

A premium, interactive birthday surprise website built with HTML5, CSS3, and Vanilla JavaScript.

The project is designed as a luxury Black & Gold birthday experience for Riju, combining 3D animations, interactive effects, scratch cards, celebrations, and music into a single responsive web experience.

🚀 How to Run

Option 1 — Open Directly

No build system is required for the basic HTML/CSS/JS version.

Download or clone the repository.

Open the project folder.

Double-click index.html.

Open it in Chrome, Edge, Firefox, or another modern browser.

Option 2 — VS Code + Live Server

For the best development experience:

Open the project folder in VS Code.

Install the Live Server extension.

Open index.html.

Right-click the file.

Select Open with Live Server.

The website will open in your browser.

Option 3 — Python Local Server

If Python is installed:

python -m http.server 8000

Then open:

http://localhost:8000

🎵 Music

The project supports a local audio file:

birthday.mp3

Make sure the file is placed in the project root next to index.html.

If you rename the music file, update the audio reference in index.html or script.js accordingly.
